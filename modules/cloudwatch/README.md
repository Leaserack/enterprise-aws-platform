# CloudWatch Module

Enterprise Amazon CloudWatch Logs module for the LR SaaS platform.

## Features

- Environment-aware log group naming
- Configurable retention
- Optional customer-managed KMS encryption
- Standard or Infrequent Access log class
- Common platform tagging

## Naming

/lr-saas/<environment>/<application>

Examples:

/lr-saas/dev/eks/application
/lr-saas/prod/eks/application
/lr-saas/prod/eks/audit

## EKS

The module can be used for application and platform logs generated by EKS workloads.

The platform will later use:

- CloudWatch
- Prometheus
- Grafana
- OpenTelemetry

## Security

Applications must not write passwords, tokens, access keys, or other secrets to logs.

Production logs should use appropriate retention and KMS encryption.

## Versioning

This module is consumed using immutable Git tags.

Example:

module "cloudwatch" {
  source = "git::https://github.com/Leaserack/enterprise-aws-platform.git//modules/cloudwatch?ref=cloudwatch-v1.0.0"
}
